# Encuesta Los Cuates

Encuesta móvil de un minuto sobre cócteles con tequila en lata personal (estudio académico independiente; no es comunicación oficial de Los Cuates ni de Quala).

- **Encuesta en línea:** https://whafonsecav.github.io/LosCuates/
- **Link para la historia de Instagram:** https://whafonsecav.github.io/LosCuates/?src=ig
- `index.html`: la encuesta (una sola página, pensada para celular).
- `backend/Code.gs`: Google Apps Script que guarda cada respuesta como una fila en Google Sheets.
- `analizar.py`: resume el CSV descargado de la hoja (`python analizar.py respuestas.csv`).

No pide nombre, correo ni teléfono. Solo para mayores de 18 años.
